# GIFさがし

日本語に強いGIF検索アプリ。タップ（クリック）でGIFのURLをコピーして、Discordに貼るだけ。
iPhone・PCのどちらでも「アプリとして追加」して使えます（PWA）。

## できること
- **日本語キーワードを英語に言い換えて検索**
  - ネットスラング辞書を内蔵（草→lol、ぴえん→pleading、おつ→good job など約400語）
  - 辞書にないことばは翻訳サービス（MyMemory）で英語に変換（設定でオフにできます）
  - 候補ワードがボタンで並ぶので、ワンタップで切り替え可能
- **自分用の言い換え辞書**（設定で「ことば = 英語」を追加）
- **お気に入り（★）と履歴**
- **マイタグ**：GIFに好きな日本語タグを付けると、次からそのことばで一番上に出る
- **端末間の引っ越し**：設定の「書き出し／読み込み」でお気に入りと辞書を移せる

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `styles.css` | 見た目（ライト／ダーク対応） |
| `app.js` | 検索・コピー・お気に入りなどの動き |
| `dict.js` | 日本語→英語の言い換え辞書（自由に追加OK） |
| `manifest.webmanifest`, `sw.js`, `icons/` | アプリとしてインストールするための設定 |

## 使い始める準備
1. https://partner.klipy.com/api-keys でKLIPYのAPIキーを発行（無料。テスト用キーは1時間100回まで）
2. アプリを開いて ⚙ 設定 にキーを貼り付けて保存
   - キーは各端末のブラウザ内だけに保存され、ファイルには書かれません

## PCで試す
```
python -m http.server 8765 --directory gif-sagashi
```
→ ブラウザで http://localhost:8765 を開く。

## iPhoneで使う（ネットに公開が必要）
iPhoneのホーム画面に追加するには、HTTPSのURLで公開する必要があります。
GitHub Pages（無料）に置くのが手軽です。

1. GitHubでリポジトリを作り、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages で公開
3. iPhoneのSafariで公開URLを開く → 共有ボタン → 「ホーム画面に追加」
4. PC（Chrome / Edge）ではアドレスバー右の「アプリをインストール」

## 注意
- KLIPYの利用規約に合わせ、GIF本体や検索結果は端末に保存しません（URLのみ保存）。
- 画面下の「Powered by KLIPY」はKLIPYの規約で必要な表示です。
